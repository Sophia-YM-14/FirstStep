# FirstStep

Your guide to getting your first job.

FirstStep is a simple website for people who don't know what to do when
looking for a job. It has three guides: Soft Skills, Resume, and Interview.

## Pages
- Home (`index.html`)
- Soft Skills (`soft-skills.html`)
- Resume (`resume.html`)
- Interview (`interview.html`)

## How to run
Open `index.html` in your browser. Keep the `img/` folder next to the HTML files.

## Built with
HTML, CSS and a little JavaScript. Designed in Figma.
